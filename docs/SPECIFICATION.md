# Спецификация первого среза

Документ фиксирует правила, которые используются в `config/default.yaml` и
доменном ядре. Исторический интервал имеет границу `from` включительно и
`effective_to` включительно по `close_time`. Все даты нормализуются в UTC.

## Pivot

- Основной поток состоит из закрытых H1-свечей.
- `wing=2`: свеча становится кандидатом только после закрытия двух правых свечей.
- Для максимума центральный `high` строго выше левой стороны и не ниже правой.
  Для минимума применяется зеркальное правило. Это оставляет первый экстремум
  в последовательности равных значений.
- Pivot хранит `pivot_time` центральной свечи и `confirmed_time` правой свечи.
- Фильтр объёма отключён в базовой конфигурации.

## Levels

- Максимум создаёт resistance, минимум создаёт support.
- Pivot объединяются при пересечении зон одного направления.
- Зона симметрична относительно цены pivot и имеет ширину `max(price *
  zone_percent, tick_size)`.
- Новый уровень получает `created_time` и `confirmed_time` равные времени
  подтверждения pivot, а не времени исходной свечи.
- Touch означает пересечение диапазона свечи с зоной. Свеча подтверждения не
  может одновременно считаться touch.
- В базовой конфигурации breakout означает закрытие за внешней границей зоны.
  Breakout обрабатывается до touch.
- Каждая закрытая свеча, пересекающая зону, является отдельным touch; cooldown
  и повторный вход в базовом срезе не применяются.

## Replay

На каждом H1-bar строго выполняется порядок: сдвиг cursor, подтверждение
pivot, создание/объединение уровня, переходы уровня, outcome-профили,
публикация snapshot. В состояние не попадают свечи правее cursor. Скорость
является только параметром доставки событий и не меняет вычисления.

`m1_exact` предусмотрен как основной режим detail timeline. В текущем срезе
M1/M5 отображаются до H1 cursor; модель исполнения ордеров будет добавлена
следующим этапом без изменения H1-источника времени.

## Outcomes

Профиль создаёт отдельный результат для каждого touch. `quick_rebound`
ожидает три H1-свечи, `patient_rebound` восемь. Успехом считается движение
на `min_bounce_percent` от цены уровня в сторону от зоны; breakout или
истечение ожидания считаются неуспехом.
