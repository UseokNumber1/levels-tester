# ТЗ «HourBounce Replay» v2.0 — UI и Config

## 1. Экраны

Экранов два: **Review** (основной) и **Config**. Тема тёмная («терминал»),
макет варианта 1. Визуальный эталон — файл `04_HourBounce_Card_Prototype.html`.

## 2. Review — левая колонка (фиксированная ширина 360–400 px, вертикальный скролл)

- Таблица сигналов, колонки:
  `Name | Symbol | dt_place | Daily Volume | NATR | TP(arch) | SL(arch) |
   Outcome(arch) | Replay Outcome | match/mismatch`.
- Бейджи исходов: TAKE — зелёный, STOP — красный, NO ENTRY — серый,
  EXPIRED — жёлтый.
- Сверху фильтры-чипы и строка поиска по имени; сортировка кликом по
  заголовкам колонок.
- Hotkeys ↑/↓ — перемещение по строкам; клик по строке выбирает сигнал
  и перерисовывает матрицу; выбранная строка подсвечена.

## 3. Review — правая графическая область: матрица 3×3

- Строки матрицы = типы входа: «T1: касание», «T2: 1-я закрытая M5 за
  уровнем», «T3: 2-я закрытая M5 за уровнем» (подписи строк).
- Столбцы матрицы = размеры стопа: «SL1», «SL2», «SL3» + числовое значение
  размера в заголовке столбца (из активной конфигурации).
- Каждая ячейка — карточка-график (один instance Lightweight Charts):
  - свечи M5, окно `[касание − pre_candles … выход + post_candles]`;
  - часовой уровень — оранжевая пунктирная линия с ценником;
  - стоп-лосс — красная сплошная линия с ценником (после активации
    трейлинга приглушается);
  - касание — светящаяся точка на уровне + вертикальная штрих-линия времени;
  - подтверждающие свечи (T2/T3) — полупрозрачная рамка-бокс вокруг свечи;
  - вход — стрелка по направлению сделки + ценник входа;
  - активация трейлинга — маркер-бейдж «④ trail on» + ступенчатая зелёная
    линия `trail_path`;
  - выход — флажок: зелёный на трейлинг-линии (TAKE), красный на стопе (STOP),
    серый «T» (EXPIRED);
  - нумерованные бейджи событий ①②③④ у соответствующих точек;
  - бейдж исхода в правом верхнем углу карточки; иконка `ambiguous`
    при коллизии (правило 3.8);
  - степпер под графиком: «1 touch — 2 confirm — 3 entry — 4 trail/SL»;
    у T1 шаг 2 серый «N/A»; при NO_ENTRY шаги 3–4 серые; шаг исхода подсвечен
    цветом исхода;
  - строка метрик мелким шрифтом: время в сделке, R, `max_profit_pct`,
    MAE/MFE.
- Клик по карточке — модальное окно master-detail: большой график с той же
  разметкой + таблица событий (`seq, type, dt, price`).
- Тумблер «sync» синхронизирует зум и crosshair всех 9 графиков.
- Над матрицей — панель агрегатов активной конфигурации по выборке сигналов:
  winrate, PF, avg R, доля NO_ENTRY в разбивке 3×3.

## 4. Экспорт HTML

Кнопка «Export HTML» — self-contained файл: inline-JSON данных +
lightweight-charts UMD с CDN; внутри 9 графиков с разметкой, таблица событий,
шапка с параметрами сигнала и версией конфигурации.

## 5. Страница Config

Все параметры движка и UI редактируются только здесь.
Кнопка «Сохранить и пересчитать»: создаёт новую `config_version`
(payload `jsonb`), запускает `ReplayJobRunner` по всем сигналам (или выбранной
выборке), показывает прогресс-бар; до завершения job матрица отображает
прежнюю версию с индикатором «пересчёт…».
История версий конфигурации: список с датой и возможностью выбрать любую для
просмотра матрицы (сравнение версий — вне рамок v1).

## 6. Приложение А. Сводная таблица параметров (дефолты)

| Параметр | Значение | Комментарий |
|---|---|---|
| Таймфрейм | M5 | фиксирован v1 |
| Биржа | Binance Futures, USDT-M | фиксировано |
| Таймзона | UTC | хранение и UI |
| `confirm_window_w` | 20 свечей | окно ожидания подтверждения от касания |
| Правило подтверждения | close за уровнем в сторону сделки, строго после касания | — |
| Число подтверждений T2 / T3 | 1 / 2 | — |
| Вход T1 | маркет по `level`; при гэпе за уровнем — по `open` | — |
| Вход T2 / T3 | `open` свечи после 1-й / 2-й подтверждающей | — |
| Единица SL | % от цены входа | альтернативы: ×NATR, пункты |
| `sl_sizes` | 0.5 / 1.0 / 1.5 | S1 / S2 / S3 |
| Режим TP | трейлинг | фиксированного TP нет |
| `tp_trail_activate_pct` | 1.0 | активация при +1 % прибыли в цене |
| `tp_trail_distance_pct` | 1.0 | дистанция трейлинга после активации |
| Коллизия стоп + трейлинг в свече | STOP | `ambiguous = true` |
| `life_window_t` | 288 свечей (24 ч) | окно жизни сделки, далее EXPIRED |
| `pre_candles` / `post_candles` | 30 / 30 | окно графика вокруг событий |
| Котировки | on-demand под окно сделки | кеш `candles_m5`, полная история не хранится |
| Экспорт | HTML self-contained | — |
| Авторизация | нет | локально, single-user |
